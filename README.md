# Qualcomm APQ8016E (Snapdragon 410) Documentation

Qualcomm DragonBoard 410c [was released in 2015][qualcomm-announcement], as a
maker-friendly development board built around the Qualcomm APQ8016E SoC, whose
marketing name is Qualcomm Snapdragon 410E.

In conjunction with that board, Qualcomm published a lot of internal
documentation for the SoC. However, after the board's support ended, Qualcomm
removed the documentation from [their website][qualcomm-apq8016e-tools].

This repository contains the published documentation, downloaded from
[the last available snapshot on the Web Archive][web-archive-tools].

## Usage

The documentation is in the `docs/` directory.

The prompt used to generate everything is in the "Authorship" section below.

## Structure

The following files are human-generated.

* `README.md` - this file
* `.gitignore` - version control exclusions

The `docs/` directory contains the downloaded documentation.

Documents are named according to the following pattern:
`Qualcomm.APQ8016.Hardware.Register.Description.LM80-P0436-13.RevC.pdf`.
`Qualcomm` is the vendor, `APQ8016` is hardware model number,
`Hardware.Register.Description` is the document title, `LM80-P0436-13` is the
document number, and `RevC` is the version information. Most of this information
can only be determined after the document is downloaded -- the URL is not a
reliable indicator of the document's contents.

For naming purposes, the DragonBoard 410c is considered its own product, and is
considered to be produced by Qualcomm. Example filename:
`Qualcomm.DragonBoard410c.Sensors.Porting.Guide.LM80-P0436-9.RevC.pdf`.

The `scripts/` directory contains AI-generated code and configuration files used
to download the documentation. The code was generated and executed by
[Google Antigravity][google-antigravity].

The `temp/` directory serves as a scratch space for AI agents and for the
generated code. The directory is excluded from version control via a
`.gitignore` entry.
